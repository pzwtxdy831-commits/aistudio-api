怎么添加账号
  1. 在要用的 Chrome 配置文件里装一次扩展：打开 chrome://extensions → 开「开发者模式」→「加载已解压的扩展程序」→ 选 AIS反代\extension 文件夹。
  2. 打开那个配置文件的 Chrome 窗口，扩展会自动开一个固定的 AI Studio 标签页，几秒后这里就会出现这个账号并开始轮询。
  3. 不想让某个配置文件参与：点扩展图标取消「这个配置文件参与轮询」，或在这里关掉「启用」。
  4. 那个配置文件的窗口关掉后账号会显示「未打开」，重新打开会自动恢复。
